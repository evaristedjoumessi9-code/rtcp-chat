# RTCP CHAT
    Ce projet est un systeme de chat peer to peer basee sur WebRTC et utilisant un seveur express et socket.io.
    Ce projet permet principalement d'initier une communication peer to peer entre deux navigateur permettant ainsi
    de passer des appels video et d,envoyer des messages textes.

    il comporte les fichiers suivants:
        backend.js:
         ce fichier comporte le code du back-end
        
        index.html:
            Ce fichier comporte l'implementation front-end de WebRTC
